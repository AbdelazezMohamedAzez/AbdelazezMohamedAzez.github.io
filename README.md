## How the Website Works

The website is published through GitHub Pages.

The main page is:

```text
index.html
```

Any update to `index.html` pushed to the `main` branch will update the live website after GitHub Pages finishes deployment.

---

## How to Update

Basic update workflow:

```bash
git status
git add index.html README.md
git commit -m "Update portfolio website"
git push origin main
```

After pushing to `main`, check the live website to confirm that the update was published correctly.
